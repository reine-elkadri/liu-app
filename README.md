# ProjectApp3 - Student Attendance Manager

A Flutter mobile app for managing student attendance, built for teachers/admins to track and record student attendance efficiently.

## Features

- 🔐 User login/authentication
- 📊 Dashboard overview
- 👥 Student list management
- ➕ Add new students
- ✅ Mark and track attendance

### Prerequisites
